# qec-research
 QEC practice project

Overview:

This project started as way for me to practice QEC and Quantum Circuit generation but as it went on I also started wondering if I can use it for AI training or any other AI development application.
That is how we reached the current point in the project where I have made hybrid neural network integrating PyTorch classical attention mechanisms with a Qiskit simulated Quantum Feed Forward Network.

Technologies Used:

- Qiskit
- Stim
- Pytorch
- Torch.nn
- Python
